# ITLEO Ukraine — Premium Edition

Повністю оновлена преміальна українська версія сайту ITLEO.

## Структура

- `index.html` — контент, SEO та семантична структура
- `styles/base.css` — токени, базова типографіка та анімації
- `styles/components.css` — grain, glass, кнопки та спільні блоки
- `styles/sections/` — стилі секцій: header, hero, signal, about, services, work, process, founder, contact, footer
- `scripts/main.js` — меню, шапка, форма
- `scripts/animations.js` — reveal, hero-анімація, відео та magnetic
- `assets/` — favicon та зображення

## Локальний запуск

```bash
python3 -m http.server 8000
```

Відкрийте `http://localhost:8000`.
