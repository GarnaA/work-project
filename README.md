# ITLEO Ukraine — Premium Edition

Повністю оновлена преміальна українська версія сайту ITLEO.

## Структура

- `index.html` — контент, SEO та семантична структура
- `style.css` — cinematic hero, liquid glass, адаптивний дизайн та анімації
- `script.js` — мобільне меню, reveal-анімації, accessibility для відео та форма
- `favicon.svg` — favicon ITLEO Ukraine
- `assets/` — локальні ресурси

## Локальний запуск

```bash
python3 -m http.server 8000
```

Відкрийте `http://localhost:8000`.
